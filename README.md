# Ahoj 👋

Jsem technik z výroby s přesahem do Pythonu, dat a AI automatizace.
Ve volném čase vyvíjím a provozuji automatizované systémy běžící 24/7 na serveru – od napojení na API přes logování
a hlídání chyb až po testy a vyhodnocování dat.
Hledám technickou pozici, kde propojím znalost výroby s daty a automatizací.

**Ukázky:**
- [production-data-analysis](https://github.com/valisj-cyber/production-data-analysis) – OEE a Pareto prostojů z výrobních dat (pandas, matplotlib)
- [llm-report-automation](https://github.com/valisj-cyber/llm-report-automation) – hlášení ze směn převedená přes LLM na strukturovaná data (Claude API)
- [exchange-bot-skeleton](https://github.com/valisj-cyber/exchange-bot-skeleton) – kostra bota: API burzy, ošetření chyb, logování (ccxt)
